# 魔芋 Moyu

**面向 PotPlayer 的 Windows AI 双语字幕工作台。** 本地提取或识别源字幕，联网翻译为简体中文，生成双语字幕并归档；识别与翻译运行在播放器之外，不向 PotPlayer 注入插件。

**当前源码：1.2.0-rc.1（候选）** · C# / .NET Framework / WinForms · 本地识别 + 联网翻译

## 能做什么

- **完整任务流程**：拖入视频或从播放器检测提示开始，查看阶段、用时和进度，支持取消、缓存复用和断点恢复。
- **优先复用字幕**：先选取对应源语言的旁置/内嵌文本字幕，没有可用字幕再调用本地 Whisper；提供 12 种源语言选项，默认日语，翻译目标为简体中文。语言选项不等于各语言都已完成同等质量验收。
- **两档翻译**：快速档优先出片；质量档在共享基础译文上增加全片规则检查与有限重点复核，思考由用户选择。
- **双语输出与字幕库**：视频旁发布双语字幕，归档源文、中文与双语版本；保护已有用户字幕。库页面显示最近 100 个归档。
- **轻量播放器联动**：独立无窗口检测器按需唤起主程序；生成字幕仍需用户确认，不因发现视频自动付费。
- **原生桌面界面**：任务、字幕库、设置三页，支持缩放与滚动、托盘、取消及键盘操作；不需要浏览器运行时。

## 快速档与质量档

当前源码版本 **1.2.0-rc.1**。新增精修仍为候选功能，标准方案仍是质量档默认；不将更多请求或全片覆盖等同于更高翻译质量。

| | 快速档 | 质量·标准 | 质量·精修（候选） |
|---|---|---|---|
| 底稿 | 不思考，轻量上下文与术语增强 | 复用同策略底稿 | 复用同策略底稿 |
| 后处理 | 原有规则修复 | 全片规则扫描 + 最多6个重点场景 + 有限修复 | 全片提案 → 候选复核 → 定向一致性检查 |
| 思考 | 关闭 | 复核可选，默认关闭 | 可选，默认开启 |
| 网络/已有字幕参考 | 不使用 | 可选 | 可选 |
| 成本取向 | 不增加固定轮次 | 有限重点检查 | 用户主动投入更多时间与调用 |

快速档保留现有速度取向，新增忠实约束、最多4条已有前文中文和相关术语/冲突保护。精修第一轮不改译文；第二轮仅采纳确认且与提案一致的候选；最后一轮只能回退已改条目或记录疑点，不能再任意重写。

标准复核累计最多10次请求、180秒（不思考）/480秒（思考）。精修有独立时间/请求/输出预留上限，0可不限累计额度，但仍是固定三阶段、每窗口至多两次实际请求；开始前再次确认成本。预算不等于实际账单。

联网需独立Brave密钥与隐私确认；本地SRT参考要每个任务确认对应作品。联网默认关闭，旧配置不会自动切精修。完整预算范围、恢复行为和未实现部分见[翻译策略与验收](docs/quality-tier.md)。

## 开始使用

本仓库是**源码交付**，不包含 PotPlayer、FFmpeg/Whisper 可执行文件、识别模型或用户配置；并非下载仓库即可使用的独立安装包。

1. 在可写目录准备源码与本地依赖；Windows 10/11，.NET Framework 4.8，Windows PowerShell 5.1 或 PowerShell 7。硬件要求取决于选用的 Whisper 模型和后端。
2. 按[安装与配置说明](docs/development.md#本地安装)准备依赖并构建。已有程序运行时只构建到暂存目录，不覆盖正在使用的程序。
3. 打开魔芋，在“道具设置”填写可用的 API 地址、模型和密钥，选择源语言、档位及字幕库目录。深度思考还需要服务端支持本项目发送的思考参数。
4. 拖入单个视频并开始。字幕生成后由 PotPlayer 自身加载，不额外注入播放器脚本。

模型与搜索 API Key 保存在独立 Windows 凭据项，不写进设置文件。源字幕、上下文、译文及相关参考会发送到你配置的翻译服务；开启搜索还会将必要短语发给搜索服务并访问来源网页。本地识别不意味着全流程离线。日志、路径、字幕与质量报告也应作为私人数据保管。

**常用操作**：Ctrl+O 选择视频；设置页 Ctrl+S 保存。关闭窗口会留在托盘，完全退出请使用托盘菜单。“使用 PotPlayer 时自动启动魔芋”会管理当前用户登录启动项；退出魔芋后，检测器要等新播放器进程才再次唤起，仅在已有播放器中切换视频不会重新唤起。

## 验证与项目边界

项目具备真实任务、缓存恢复、预算控制、修改审计、原生UI、字幕保护及更新回滚，不是仅有界面的演示原型。**工程可用不等于新增精修已经通过成熟质量验收。**

- 离线：质量档65项断言、新增演进65项断言；另有翻译、UI、检测器、安装器与程序自检。套件有重叠，不累加为功能数。
- 真实接口：5组快速档新旧成对小样本计时没有明显中位耗时退化；最终三阶段机制在英语/日语各12条的小样本中各修正1处预置否定错误，其他11条未改。
- 全片实测：较早的直接采纳设计完成过853条日语全片运行，但暴露自信误改，因此已废弃该采纳设计；其计时不能冒充最终三阶段全片验收。
- 仍待验：最终精修跨语言/跨类型的两部整片与人工盲评、真实Brave搜索、新设置页175%缩放交互；复杂长媒体识别、新机器安装与分发也有边界。详细结果和限制见[验证记录](docs/quality-tier.md#验证记录与发布判断)。

运行全部离线验证：

~~~powershell
./tests/run-all-tests.ps1
~~~

在临时目录构建和测试，不调用真实模型，不需要生产密钥、播放器、FFmpeg 或 Whisper。详细命令和证据边界见[开发与验证](docs/development.md)。
