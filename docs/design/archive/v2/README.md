# 魔芋 V2 · 翻译道具箱

独立交互设计稿，保留上一版和现有 Windows 应用。直接打开 moyu-v2.html 即可，无需联网或安装依赖。

## 这次的变化

- 用漫画蓝、蛋黄、纸白和深墨线建立明确的主次；不再沿用清淡的水彩配色。
- 重绘厚切魔芋：不添加五官和四肢，保留参考中的斑点、厚度与斜切面。
- 首页突出插画与视频入口；翻译中收起大图，集中展示进度、双语对白和处理步骤。
- 字幕库、完成页、设置页使用同一套配色、线条与控件。窄窗口可纵向滚动，较小桌面窗口支持内容区滚动。

## 预览与边界

顶部可切换等待、翻译中、完成；侧栏切换字幕库与设置。可演示文件选择/拖入、12 种语言（日语默认）、筛选搜索和开关。语言列表与 src/SourceLanguages.cs 一致。

本稿不读取视频内容、不上传、不识别翻译、不启动 PotPlayer、不写入配置。所有进度、字幕、视频条目均为示例；设置只在当前页面内存中变化。检测器和主程序未改动，未构建、提交或推送。
