# 字体与一体化标题栏 · V3 设计预览

这是独立浏览器设计稿，不修改原生应用、配置、密钥、检测器或字幕任务。

## 查看

直接打开 index.html，或通过仅绑定本机回环地址的静态服务打开。素材引用现有 Assets/Brand，不替换批准的魔芋插画。

## 设计

- 48px 一体化顶部栏；蓝色侧栏通顶，右侧延续米白纹理，合并重复页面标题。
- 当前主机已安装 Noto Sans SC，浏览器实际字体检查确认使用该字体。预览没有打包第三方字体，其他主机缺失时回退到微软雅黑。此前建议的是思源黑体；本次试稿实际使用 Noto Sans SC，不能把该预览当作已部署思源字体。
- 主标题 34px，页标题 25px，卡片标题 16px，正文和主要操作 14–15px。品牌保留较强字重，表单以普通与中等字重为主。
- 深墨线集中在上传区域及主要按钮，普通表单使用更轻的边框；保留现有蓝黄配色和轻纹理。

## 操作与边界

支持三页切换、语言摘要、选择单个视频后主要按钮启用、设置开关、展示密钥按钮、最大化和 Esc 还原的浏览器内示意。选择视频只显示名称，不读取或上传其内容；无服务调用、存储或真实任务。所有保存、生成、目录选择及窗口关闭动作均明确提示为示意。不要输入真实密钥。

标题栏的拖动、贴靠、系统菜单、边缘缩放、DPI 和原生关闭到托盘尚未实现；正式落地需另行验证 WinForms 非客户区行为。本稿不是原生窗口截图，也不是新的真实字幕库。
