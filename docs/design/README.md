# 魔芋 · 翻译魔芋轻卡通视觉原型

这是最早期的浏览器视觉原型，用于确定造型与配色方向，**不是生产界面**。成品已接入原生 WinForms 主程序，见 `docs/design/native/`；界面主题与各项说明见仓库根目录 `README.md` 的“翻译道具箱视觉主题”一节。现有播放器联动、后台检测器、字幕引擎、用户设置和 Git 提交均未改动。

## 打开

直接在浏览器中打开 `moyu-konjac-concept.html`。不需要安装依赖、联网或启动翻译服务。右上角可切换“等待视频 / 翻译中 / 已完成”，左侧可切换任务、字幕库和设置。

## 视觉方向

- 以用户提供的翻译魔芋参考图为造型依据：米灰色厚块、细小杂点、可见侧面和底部切面。
- 不添加眼睛、手脚；不采用参考图的红色爆炸背景或人物。
- 奶油白、清浅蓝、深蓝灰文字，少量淡黄点缀。
- 卡通元素集中在品牌和待机主视觉；处理中和完成页优先展示任务、字幕与操作。
- `konjac-mark.svg` 是可编辑矢量图；界面以 HTML/CSS 绘制。本次内置图像生成未返回可用图片，未使用备用生成 API 或新增运行库。

## 文件

- `moyu-konjac-concept.html`：交互式设计原型。
- `konjac-mark.svg`：参考原型绘制的魔芋品牌图形。
- `task-ready.png` / `task-busy.png` / `task-done.png`：三种任务状态的实际浏览器渲染图。
- `library.png` / `settings.png`：延展页面设计。
- `design-checks.json`：本次 24 项原型检查结果。

## 交互边界

文件选择只取文件名；不会读取视频内容、上传、识别或翻译。播放、目录等示意按钮只显示解释消息。示例进度、时间、字幕和归档不是真实任务结果。语言设置仅保存在当前页面内存，不会写入应用配置。原型不包含用户密钥输入。

检查包含：三个任务状态、三个导航页、12 种语言和日语默认、语言同步、文件选择与重置、示意按钮，以及 1440 / 1040 / 640 像素宽度下的横向布局与图形加载。原型在低窗口高度下可滚动，不代表原生应用已完成 DPI 或可访问性验收。

后续接入应用时，应保留现有真实任务状态与错误提示，不用示例内容替代真实字幕、封面或进度，并继续验证原有回归测试。
