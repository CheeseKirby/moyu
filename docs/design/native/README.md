# 已采用的原生界面

“翻译道具箱”视觉已接入 WinForms 主程序，并叠加 V3 字体与一体化标题栏、V4 留白与主题细节。仍使用原有字幕、语言、设置、归档与自动唤起逻辑，不引入浏览器运行时。

蓝色侧栏、黄色导航与主要操作、米白底纸、墨线控件和魔芋品牌图形共用一套主题。插画从定稿 SVG 输出为高清 PNG 并内嵌到可执行文件；窗口与托盘图标也采用同一魔芋造型。

待机展示完整插画，开始任务后切换紧凑头部与真实处理进度；失败提示不会被完成画面替代。正式应用不使用 HTML 原型中的示例字幕、假进度、示例归档或未接通的按钮。字幕库与服务设置保留实际已支持的操作。

## 一体化标题栏与圆角

- 48px 一体化的自绘标题栏：左侧显示当前页面名，右侧为自绘的最小化/最大化/关闭按钮；标题栏空白处可拖动窗口，双击可最大化/还原。
- 蓝色侧栏通顶，右侧工作区延续米白底纸；标题栏与侧栏共用同一套主题。
- 在 Windows 11 上采用系统原生圆角（`DWMWA_WINDOW_CORNER_PREFERENCE`），最大化时自动回归直角；Windows 10 不提供该系统圆角能力。
- 窗口获得/失去焦点时强制重绘标题栏与窗口按钮，保证主题不丢失；同时拦截系统非客户区绘制，避免切回焦点时闪出默认边框。

## 高 DPI 清晰度

- 程序已声明 DPI 感知；自绘文字在设备像素上用点字号以 ClearType 渲染，175% 缩放下中文清晰不发虚。
- 字体优先 Noto Sans SC，缺失时回退微软雅黑；主标题 34px、页标题 25px、卡片标题 16px、正文 14–15px。
- 上传卡片带纸胶带；侧栏底部为描边小魔芋线稿与播放器连线（不拦截鼠标、对辅助技术隐藏）。

## 性能

纸张/印刷纹理采用“预缩放贴片 + 整数平移”，避免高 DPI 下逐像素重采样（高 DPI 纹理填充约快 17 倍）；纹理画刷复用，窗口双缓冲，页面切换流畅。

本目录为隔离 UI 测试程序绘制的真实 WinForms 窗口截图；测试条目与进度不是实际翻译结果，不包含用户视频或密钥。

验证：界面回归 14 组、检测器 8 组、核心自检 11 组、内置 UI 自检 8 组，共 41 组通过。覆盖最小窗口、导航高亮、内嵌图形、成功/失败状态、源语言、字幕库、自动唤起、原生标题栏命中与缩放/最大化、动画、纹理确定性和双缓冲。最小窗口允许纵向滚动，无横向滚动。截图基于测试主机的实际 DPI；不代表多台显示器或所有缩放比例均已人工验收。

## 纸面纹理与交互细化

米白工作区采用低对比度纸纤维与颗粒，蓝色侧栏采用轻微印刷网点，蓝黄主要按钮沿用细颗粒；白色内容卡片、输入框与字幕列表保持纯净。纹理使用两张 192×192 的固定缓存图块，以窗口坐标对齐子面板，不在每次绘制时生成噪声。

按钮悬停约 140 ms，按下约 65 ms、释放约 120 ms，主要按钮有轻微下压；导航选择约 170 ms，进度前进约 220 ms。点击、页面选择和真实进度值立即生效；进度回退、重置和到达 100% 不等待动画。保留键盘空格操作及焦点提示。

每个有过渡的控件仅在动画期间启用一个计时器，结束后停止；隐藏、禁用、销毁时收尾。遵循系统客户区动画设置，高对比度或远程桌面会关闭动画，高对比度或系统要求禁用重叠装饰内容时不绘制纹理。

新增四组验证覆盖中间帧、快速反向、键鼠即时操作、减少动画策略、隐藏与释放清理、真实进度及重置完成、固定纹理密度和子面板拼接。截图等待过渡自然结束后拍摄；这些是隔离测试，不替代不同机器和 DPI 下的人工体验。
